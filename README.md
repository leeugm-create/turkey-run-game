**Pardon Run — The Great Turkey Escape.** An original side-scrolling chase game that plays offline in a desktop browser from static files, no network requests. You are the turkey, and Thanksgiving is coming: sprint from the farmyard through the barnyard into the kitchen, jumping hay bales, crates and lit ovens, ducking the carving knives the farmer throws, grabbing corn and pumpkins on the way. Every stumble costs a life and lets the farmer close in — three stumbles, or one grab, and the run is over. Survive to the Freedom Fence at 1,150 m and you are pardoned. Hand-drawn canvas art, synthesised sound effects, a farmer who telegraphs every throw, and stages that keep getting faster. Keyboard and mouse: Space/↑/click to jump (again mid-air to flap), ↓ to duck, P to pause, R to run again.

## Run it

```sh
python3 -m http.server -d game 8000   # then open http://localhost:8000 in desktop Chrome
```
